# capture

İçeriği önce sır açısından denetle; sır varsa kaydetme. brain.py capture --input <yerel-geçici-dosya> --kind note veya task kullan. Mesleki ve entelektüel alanları ayrı seç; belirsiz içerik private olur. Yerel geçici dosyayı vault dışında tut ve içeriği loglama.

Komutları vault kökünden ayarlardaki Python ile `00-System/Scripts/` altında çalıştır. Paylaşılan gizlilik ilkeleri için `00-System/Policies/Privacy.md`, kullanım için `START-HERE.md`.
