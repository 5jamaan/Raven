# project-review

brain.py project-review çalıştır; ilgili proje notunu oku. Son güncelleme, çıktı kanıtı, next_action, review_date ve Waiting kayıtlarını kontrol et. Bilinmeyen başarı veya seviye uydurma. Sonucu yeni review notuna yaz.

Komutları vault kökünden ayarlardaki Python ile `00-System/Scripts/` altında çalıştır. Paylaşılan gizlilik ilkeleri için `00-System/Policies/Privacy.md`, kullanım için `START-HERE.md`.
