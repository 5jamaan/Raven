# daily-review

brain.py daily-review çalıştır. Gecikenler, beklenen yanıtlar, eksik sonraki adımlar, açık sözler ve Threads Active/Waiting içeriğini ilgili ölçüde değerlendir. Yeni bir inceleme notu üret; kaynak notları onaysız ezme. Tek anlamlı sonraki adımı belirt.

Komutları vault kökünden ayarlardaki Python ile `00-System/Scripts/` altında çalıştır. Paylaşılan gizlilik ilkeleri için `00-System/Policies/Privacy.md`, kullanım için `START-HERE.md`.
