# Raven public source

This is the public software repository, NOT a personal Raven vault.
Do not enable template hooks, add personal notes, copy live vault history, or connect external accounts here.
Runtime code and empty note templates are in template/. Install into a NEW directory outside this repository with tools/setup.py.
Run tools/release_check.py and the Windows test suite before publishing.
Never publish account identifiers, credentials, personal sessions, local verification receipts, machine-specific paths, databases or backups.
