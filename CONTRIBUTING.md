# Contributing

Keep source changes in this repository and private work in a separate vault. Run both Windows test suites and the release check before submitting a pull request. Add focused tests for privacy, capture, storage, installation or concurrency changes.

Do not attach your personal vault, queue database, provider transcripts, credentials, machine paths or screenshots containing personal data. Use synthetic fixtures. Do not claim a supported UI integration from a mocked test alone.

Avoid hard-coded user paths or inherited account approval. Document provider/version assumptions and any change to the cloud processing boundary. Changes to source templates do not update existing installed vaults automatically.
